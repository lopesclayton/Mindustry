Implemented in this source snapshot:
- Wigo application ID and Android/Kotlin build plugin compatibility.
- Removed redundant compileOnly android.jar (AGP supplies the boot classpath).
- External Arc links require a one-use Android device credential confirmation.
- Exact privacy URL below remains accessible without device authentication.
- Incoming mindustry:// server invitations require the same confirmation before
  connecting, via JoinDialog.connect after the original in-game join confirmation.
  Callback returns to the game thread; the entry does not request credentials twice.
- Requests do not persist authorization; no lock, cancellation or recreation
  denies the requested action. Runtime validation is still required.
- About contains independent-adaptation text, policy and modified-source links
  in English and Brazilian Portuguese. Upstream credits remain intact.
- Android no longer fetches community server lists during JoinDialog startup.
  User-triggered community-list fetches (including settings) require device
  credentials through Platform.withParentalApproval. Approved work is posted to
  the game thread; the default platform method denies unimplemented Android calls.
- JoinDialog connect/reconnect and HostDialog hosting request one-use approval
  before showing connection progress or initiating network operations. Reconnection
  captures the requested endpoint and its approved retry does not prompt twice.
- PvP map auto-host requests approval and rechecks the map/game state afterward.
- Server-list refreshes, LAN discovery and individual server pings request approval.
  One list refresh batches local/remote/community work under one authorization;
  joining/hosting still require their own approval. Closed Android dialogs discard
  pending refresh work. Reordering cached server entries needs no network approval.

NOT READY FOR PRODUCTION:
Android mod imports and startup now reject Java metadata, executable/archive
payloads (.jar/.dex/.class/native libraries) and scripts, including wrapped ZIPs.
Data-only mods remain supported. Rejection does not delete existing mod files.
Java release downloads are blocked before requesting release assets. Script
execution and Android platform JAR loading have additional fail-closed guards.
The Android scripting console cannot execute external scripts either.
Desktop behavior is unchanged. These restrictions were explicitly authorized.
Mod discovery/network parental entrypoints still need final integration review.
Final launcher/game identity and store assets are not finished. Device runtime,
rendered layout, accessibility, gameplay and lifecycle tests remain pending.
No signed final AAB or Play submission is represented by this source snapshot.
